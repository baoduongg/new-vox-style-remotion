## 2. Thiết Kế Thumbnail 2D Vector Tương Phản Cực Đại (High-CTR Thumbnail)

Quy tắc 3 điểm chạm thị giác chuẩn cho video triệu view:
```
[Bên Trái: Thất bại / 1,100°C CRUDE IRON BENT + Dấu X Đỏ] ── vs ── [Bên Phải: Kỳ tích / 1,500°C PURE STEEL + Chém đứt đe sắt + Ánh Vàng]
                                                     ▲
                                        [Ở Giữa: Stickman Viking há hốc mồm shock
                                            cầm đồng hồ nhiệt bốc cháy]
```
