# Hướng Dẫn Prompt & Visual Sourcing Đa Thể Loại (Universal Stickman Prompts)

Tài liệu hướng dẫn tạo hình ảnh cho video **Stickman 2D Animated Explainer** đa chủ đề (Khoa học, Y tế, Tài chính, Tâm lý, Công nghệ, Sinh tồn & Lịch sử).

---

## 🎯 1. Công Thức Prompt Gemini Đa Năng (The Universal Formula)

```text
Clean 2D vector cartoon animated documentary style illustration, in the style of Kurzgesagt and OverSimplified. [Subject / Character Archetype & Action]. [Rich 2D Vector Background / Laboratory / City / Anatomy / Sci-Fi Grid]. [Technical Insets / Diagrams / Formulas / Charts / Arrows]. Smooth clean line art, bold black vector outlines, vibrant flat colors with soft cel-shading, playful educational aesthetic. [In-Image Typography & Language Constraint]. 16:9 widescreen.
```

### ⚠️ Quy Tắc Cốt Lõi:
- **Style DNA**: `Clean 2D vector cartoon animated style, bold black vector outlines, flat colors, soft 2-tone cel-shading`.
- **Nhân vật**: `Expressive white round-headed stickman with dot eyes and exaggerated comedic emotions`.
- **Cấm**: `photorealistic, 3D render, dark grunge, textured parchment, messy sketch`.
- **Ngôn ngữ chữ trong ảnh**:
  - *Tiếng Anh*: `All visible text, labels, infographics, and diagram annotations must be strictly in clear English typography with Latin alphabet only, 16:9 widescreen.`
  - *Tiếng Việt*: `All visible text, headers, and diagram labels must be strictly in clear Vietnamese typography with correct diacritics (e.g., 'LÃI KÉP 10%', 'DOPAMINE NÃO BỘ'), 16:9 widescreen.`
