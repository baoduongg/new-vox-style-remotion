# Stickman Storytelling Style Guide (2D Vector Animation)

Đây là tài liệu quy chuẩn phong cách thị giác (Visual Style Guide) cho thể loại **Stickman Storytelling & Dramatic Narrative** (tham chiếu từ các kênh hàng đầu như *OverSimplified*, *Brew*, *Scribble Stories*, *TED-Ed*, *Tales of History*).

---

## 🎨 1. DNA Thị Giác Cốt Lõi (Core Visual DNA)

Phong cách này là **Hoạt hình 2D Vector Cartoon hiện đại** với nét vẽ sắc nét, nhân vật giàu cảm xúc và kịch tính hóa từng khoảnh khắc:

### 1. Nhân Vật Stickman Biểu Cảm Vượt Trội (Expressive Storytelling Stickmen):
- **Đầu tròn trắng (hoặc có tông da/râu tóc theo nhân vật lịch sử)** với viền đen dày đậm nét (`stroke-width: 4-6px`).
- **Kho biểu cảm kịch tính & hài hước**:
  - *Kẻ lừa đảo / Mưu mô*: Lông mày nhếch một bên, nụ cười nhếch mép gian xảo, hai mắt híp lại, bàn tay xoa xoa vào nhau.
  - *Nạn nhân sốc tột độ / Bị bắt quả tang*: Mắt mở to tròn xoe chiếm nửa khuôn mặt, con ngươi co lại thành chấm nhỏ, mồ hôi bắn tung tóe, miệng há hốc `D:`.
  - *Đau đớn / Kiệt quệ / Sinh tồn*: Quầng thâm mắt dày, khóe miệng trĩu xuống, cơ thể run rẩy với các vệt ziczac, nước mắt rơi thành dòng.
  - *Giận dữ bốc hỏa*: Lông mày vát chéo dữ dội `\ /`, hơi nước/khói bốc ra từ tai, mặt ửng đỏ cam, hàm răng nghiến chặt.
  - *Tự tin / Hống hách*: Cằm hất cao lên trời, mắt nhắm nghiền kiêu hãnh, ngực ưỡn về phía trước.
- **Trang phục theo bối cảnh đời sống hiện đại & thực tế**:
  - *Dân văn phòng / Công sở*: Áo sơ mi trắng xộc xệch, cà vạt nới lỏng, thẻ đeo cổ nhân viên, đôi mắt quầng thâm vì overtime.
  - *Startup Founder / Diễn giả phông bạt*: Áo cổ lọ đen hoặc blazer hiện đại, đeo kính gọng tròn sành điệu, tay cầm mic thuyết trình.
  - *Freelancer / Con nghiện màn hình*: Áo hoodie rộng thùng thình, quần short, tóc bù xù, trùm chăn ôm laptop trong bóng tối.
  - *Kẻ lừa đảo công nghệ / Hacker*: Áo khoác đen có mũ trùm kín nửa mặt, ánh sáng xanh màn hình phản chiếu lên kính.
  - *Chuyên gia làm giàu dỏm (Fake Guru)*: Bộ vest bóng lộn cài hoa cài áo, đeo đồng hồ Rolex vàng to tướng, đứng tựa vào xe mui trần.

---

### 2. Bối Cảnh 2D Kể Chuyện Hiện Đại & Đời Thường (Modern Story Environments):
- **Phòng ngủ tối với ánh sáng xanh smartphone**: Phòng ngủ tắt đèn tối mịt (`#1A1E24`), chỉ có một chùm sáng xanh neon (`#64B5F6`) từ màn hình điện thoại rọi thẳng vào khuôn mặt nhợt nhạt của nhân vật.
- **Văn phòng công ty hiện đại / Bàn làm việc ngập deadline**: Bàn làm việc kính hiện đại (`#E0E0E0`), máy tính hiển thị hàng chục tab trình duyệt và phần mềm chat Slack/Zalo đỏ rực thông báo, cốc cà phê cạn đáy.
- **Phòng họp kính chọc trời (Wall Street / Silicon Valley)**: Tường kính nhìn ra các tòa nhà chọc trời, bàn họp đá cẩm thạch đen (`#212121`), máy chiếu biểu đồ doanh thu tăng trưởng hoặc lao dốc.
- **Quán cà phê làm việc / Góc phố đô thị**: Bàn gỗ ấm cúng (`#8D6E63`), tiếng ồn ào xung quanh, đèn vàng dịu nhẹ tương phản với sự cô độc của nhân vật cắm tai nghe chống ồn.

---

### 3. Đạo Cụ Kể Chuyện Hiện Đại & Biểu Tượng Tâm Lý (Modern Props & UI Elements):
- **Màn hình điện thoại & Thông báo sốc (Mobile UI Popups)**: Khung thông báo tin nhắn pop-up, số dư tài khoản ngân hàng nhảy về 0đ (`SỐ DƯ: 0 VNĐ`), biểu đồ nợ BNPL tăng vọt, đồng hồ đếm ngược Screen Time.
- **Két sắt hẹn giờ (Timed Kitchen Safe)**: Chiếc két sắt bằng nhựa/kim loại trong suốt có nắp khóa điện tử hiển thị đồng hồ LED đếm ngược số giờ.
- **Biểu đồ tài chính & Sóng não Dopamine**: Các đường sóng biểu đồ chứng khoán/crypto màu xanh dựng đứng hoặc lao dốc đỏ rực kèm mũi tên vỡ vụn; bong bóng Dopamine màu tím trôi lơ lửng.
- **Bong bóng thoại & Suy nghĩ (Speech & Thought Bubbles)**: Xuất hiện dạng pop-in để thể hiện những toan tính ngầm, nỗi sợ hãi hoặc sự bối rối của nhân vật.

## 🌈 2. Bảng Màu 2D Kể Chuyện Chuẩn (Color Palette)

| Yếu tố | Mã Hex | Ý nghĩa tâm lý trong kể chuyện |
|---|---|---|
| **Vàng kim / Thành công / Giàu có** | `#F5C518` / `#FFD23F` | Vali tiền, ánh hào quang, thành công phi vụ |
| **Đỏ kịch tính / Báo động / Thất bại** | `#D32F2F` / `#E53935` | Dấu X đỏ, báo động cảnh sát, máu, nguy hiểm |
| **Xanh bão tuyết / Tuyệt vọng** | `#2C3E50` / `#1A252F` | Đêm đông, bão tuyết, mắc kẹt cô độc |
| **Nâu da cổ / Giấy báo vintage** | `#F5EBE1` / `#EBD8C1` | Nền tài liệu, hợp đồng giả mạo, báo chí |
| **Nét viền đen sắc nét** | `#1A1A1A` / `#222222` | Viền nhân vật, đạo cụ, đường nét truyện tranh |

## 💻 3. Component Remotion Khung Kể Chuyện Kịch Tính

```tsx
// src/components/StoryCanvas.tsx
import React from 'react';
import { AbsoluteFill, interpolate, spring, useCurrentFrame, useVideoConfig } from 'remotion';

interface StoryCanvasProps {
  headline?: string;
  chapterTag?: string;
  children: React.ReactNode;
  mood?: 'neutral' | 'dramatic' | 'suspense' | 'triumph';
}

export const StoryCanvas: React.FC<StoryCanvasProps> = ({
  headline,
  chapterTag,
  children,
  mood = 'neutral',
}) => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();

  // Hiệu ứng thở nhẹ nhàng tạo sự sống động
  const steppedFrame = Math.floor(frame / 3) * 3;
  const cameraZoom = interpolate(steppedFrame, [0, 150], [1, 1.03], { extrapolateRight: 'clamp' });

  // Màu viền và ánh sáng tùy theo mood
  const vignetteColor =
    mood === 'dramatic'
      ? 'rgba(180, 20, 20, 0.25)'
      : mood === 'suspense'
      ? 'rgba(10, 20, 40, 0.45)'
      : mood === 'triumph'
      ? 'rgba(240, 190, 40, 0.2)'
      : 'rgba(0, 0, 0, 0.15)';

  return (
    <AbsoluteFill
      style={{
        backgroundColor: '#F8F4EE',
        transform: `scale(${cameraZoom})`,
        overflow: 'hidden',
        fontFamily: '"Montserrat", "Arial Black", sans-serif',
      }}
    >
      {/* Lớp phủ điện ảnh Vignette */}
      <AbsoluteFill
        style={{
          boxShadow: `inset 0 0 120px ${vignetteColor}`,
          pointerEvents: 'none',
          zIndex: 5,
        }}
      />

      {/* Chapter Tag & Headline kể chuyện */}
      {chapterTag && (
        <div
          style={{
            position: 'absolute',
            top: 40,
            left: 50,
            zIndex: 20,
            display: 'flex',
            flexDirection: 'column',
            gap: 6,
          }}
        >
          <span
            style={{
              fontSize: 18,
              fontWeight: 800,
              letterSpacing: 2,
              textTransform: 'uppercase',
              color: '#D32F2F',
              backgroundColor: '#FFF',
              padding: '4px 12px',
              borderRadius: 6,
              boxShadow: '0 4px 12px rgba(0,0,0,0.1)',
              alignSelf: 'flex-start',
            }}
          >
            {chapterTag}
          </span>
          {headline && (
            <h2
              style={{
                fontSize: 36,
                fontWeight: 900,
                color: '#111',
                margin: 0,
                textShadow: '0 2px 8px rgba(255,255,255,0.8)',
              }}
            >
              {headline}
            </h2>
          )}
        </div>
      )}

      {/* Nội dung chính của Scene */}
      <div style={{ position: 'relative', width: '100%', height: '100%' }}>
        {children}
      </div>
    </AbsoluteFill>
  );
};
```
